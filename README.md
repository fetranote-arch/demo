## Déploiement sur GitHub Pages

1. Créez un repository GitHub (ex: `alaqeeq-website`)
2. Uploadez tous les fichiers à la racine du repository
3. Assurez-vous que le dossier `images/` contient tous les fichiers `.webp`
4. Allez dans **Settings > Pages**
5. Source : `Deploy from a branch` → branche `main` → dossier `/ (root)`
6. Cliquez **Save** — le site sera accessible sur `https://votre-username.github.io/alaqeeq-website/`
